# Derivatives lesson for student laptops

Give each student a copy of `derivatives-student.html`. They can open the file directly in a current Chrome or Edge browser; the lesson, graphs, equations, and fonts are bundled into that one file. No local server or internet connection is needed for the derivative activities.

Students work through the six pages in order. Their text notes stay in the open browser tab and are not submitted. Ask students to keep the tab open during the lesson and copy any notes they want to retain afterward.

To rebuild the file after editing the website, run `npm run build` and then `npm run offline:build`.
